# proofhex

Proof HTML/Markdown hex fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/proofhex/

## Install / run

```bash
git clone https://github.com/theworker02/proofhex.git
cd proofhex
node src/cli.js
node --test
```
